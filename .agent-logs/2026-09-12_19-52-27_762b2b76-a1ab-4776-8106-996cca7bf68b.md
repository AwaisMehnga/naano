**`POST http://localhost:8000/api/stripe/webhook`**


The CLI prints a signing secret. Put that in `.env`:

```
STRIPE_WEBHOOK_SECRET=whsec_...
```

Then restart PHP (`php artisan serve` / `composer run dev`) so config reloads.

| Event | What the app does |

There are two different “releases.” Only **cancel** is live today.

### 1. Cancel booked (already in item 4)

If the company cancels a **booked** collab **before** the live URL is submitted: ledger `release`, hold goes back to company `available_cents`, contract is voided. No Stripe call.

### 2. Pay the creator (not built yet)

Money does **not** move on draft approval. Approve only allows publish.

The trigger is **`POST /api/creator/posts/{post}/publish`**: creator attaches the live LinkedIn URL. That is payment proof.

Then, ledger only (still no Stripe charge):

1. **Capture** the company hold (`hold` → `capture`).
2. **Credit** the creator earnings wallet for `booked_price_cents` (they keep 100%).

v1 rule: one collab → one credit when **all** posts on that collab are `published`.

Cash to the creator’s bank is a **later** step: they request a withdrawal when available ≥ €100 **and** Stripe Connect `payouts_enabled`. Then Stripe **Transfer** (platform balance → Connect / SEPA). Publish does not auto-transfer.

After capture, refunds are ops (`refund` + Stripe Refund), not a creator button.
